4. 실측 재생 (HA 기록 10/14~10/28)

재생하면 위 시뮬레이션 입력이 실제 기록으로 바뀝니다. 끝나면 Comma 종료(데이터 지연) 상태로 넘어가 회색으로 바뀝니다.

확인 위치: 카드 개요 탭 왼쪽 차량 그림 아래의 외기 … / 배터리 … 줄. 값 앞의 점과 글자색이 판정 결과입니다. 주행·충전은 색 없음, 데이터 지연·통신 지연·13V 이상은 회색, 오래된 값은 “N분/시간 전”이 붙습니다. 다크/라이트 테마와 한국어/영어는 카드 안에서 바꿀 수 있습니다.
