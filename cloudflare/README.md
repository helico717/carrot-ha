# 폐기된 서버 참고 구현

현재 HA 운영은 자체 Carrot Vehicle Receiver를 사용합니다. 이 폴더의 Worker/D1/KV는
이전 구현·압축/이관 증거·호환 테스트·라이선스 보존용입니다. 새 설치/일반 업데이트에
배포하지 않습니다. `setup.ps1`은 실수로 과거 설치를 시작하지 않도록 중지합니다.
기존 운영 계정·DB를 삭제하거나 배포를 실행한 변경은 아닙니다.
