# 디버그 카드: 데이터 지연 표시

대상: `custom:carrot-dashboard-debug-card`. 일반 대시보드, HA 백엔드, comma 수집기는 변경하지 않습니다.

최신 요청에 따라 별도 안내 패널과 SOC의 마지막 측정 문구를 제거했습니다.
- stale일 때 기존 상단 배지와 차량 상태 영역에만 `차량 데이터 지연 · 40분 전` 표시.
- SOC, 충전 전력, ETA, 외기온, 12V, 공조, 지도와 충전/주행 시각 효과는 마지막 정상 수신 화면 유지.
- 지연 동안 슬라이더를 변경해도 마지막 정상 카드값을 덮지 않음. 새 입력은 충전중/주행 중/주차중 재선택 시 반영.
- 미확인·통신 오류도 별도 큰 패널 없이 기존 상태 영역에서 표시.
- 복사 JSON은 `simulated:true`, 표시 전 가상 입력은 `debug_raw`로 구분. 실제 HA 상태를 쓰지 않음.

확인: 충전중 → 데이터 40분 지연 → SOC·전력·ETA·지도 불변, 상태 영역만 변경 → 충전중/주행 중/주차중 재선택.
주행중 → 데이터 지연도 같은 방식. 라이트/다크 테마 모두 지연 배지 대비 확보.

```sh
node --test tests/debug-freshness.test.mjs tests/trip-days.test.mjs
```

변경 파일은 `custom_components/carrot_ha/frontend/carrot-dashboard-debug.js`. 실제 HA에 원격 설치하지 않았습니다. 해당 파일을 적용한 후 브라우저 강력 새로고침이 필요합니다.

차량 동작 모드는 배지와 같은 7개 상태만 제공합니다: 충전중, 주행 중, 주차중, 차량 데이터 지연, 통신 지연, 연결 확인 불가, 상태 확인 불가. 통신 지연은 차량 데이터 지연보다 우선 표시합니다.
