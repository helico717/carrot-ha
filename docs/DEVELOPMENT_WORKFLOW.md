# 개발·배포 담당과 현재 구성

## 2026-10-21 사용자 재확인 — 아래 과거 배포 설명보다 우선

1. 개발 변경은 검증·커밋·푸시 후 HA에 SSH로 직접 반영한다. 백업과 배포 파일 해시를
   확인하고 변경·검증·반영 상태를 해당 changelog에 기록한다. HA 재시작이 필요한 경우
   사용자가 수행한다. Comma 소스의 SSH/SCP 직접 수정 금지는 유지한다.
2. **새 pre-release는 사용자가 올려도 된다고 명시적으로 승인한 뒤에만 발행한다.**
   그때 저장소의 모든 관련 changelog와 Git 이력·diff를 대조해 직전 pre-release 이후
   전체 미발행 변경을 빠짐없이 포함한다. 이전 릴리즈 승인을 새 발행에 재사용하지 않는다.
3. 정식 릴리즈는 사용자의 필드 테스트 통과 보고와 명시적인 정식 발행 지시 후에만
   발행한다. 기능 구현·직접 배포 요청이나 CI 통과는 릴리즈 발행 허가가 아니다.


2026-10-15 주행 로그 이중 보관 작업의 최신 지시: **새 프리릴리즈/태그 없이 HA 직접 반영**.
코드·검증·NAS 복사·설치·사용자 재시작 대기 상태를 `driving-logs/CHANGELOG.md`에 기록한다.
아래 beta.1 발행 승인은 이미 마친 이전 작업이며 이번 변경의 재발행 승인이 아니다.

현재 운영: Comma → 자체 HAOS 차량 수신 앱 → HA. Cloudflare 경로는 폐기된 참고 구현입니다.
HA Core를 재시작해도 수신 앱은 동작합니다. 기기 전체 전원·회선 장애는 분리되지 않습니다.

| 수정 대상 | 저장소 / 위치 | 배포 |
| --- | --- | --- |
| HA 통합·화면 | helico717/carrot-ha / custom_components/carrot_ha | 검증·main 푸시·백업 후 HA SSH 직접 반영, 사용자 승인 후 누적 pre-release |
| 독립 수신 앱 | 같은 저장소 / addons/carrot_receiver | 앱 버전 갱신·검증·푸시, 앱 스토어 업데이트 |
| 차량 수집기·카메라·터미널 | helico717/openpilot / carrot-wip-model_selector-ha | 검증·커밋·푸시, 사용자가 clean Git Pull/재부팅 |
| 문서 | 해당 저장소 | 검토·커밋·푸시, 실행 코드 변경 없으면 불필요한 버전 상승 없음 |

Comma 소스는 SSH/SCP/터미널로 직접 복사·편집하지 않습니다. 설정은 Git에 들어 있는
설정 프로그램을 사용하고 저장 위치는 Git 바깥입니다. 사용자 데이터·키는 커밋하지 않습니다.
주행 로그/차계부 변경은 해당 AGENTS와 CHANGELOG 지침을 따릅니다.

2026-10-14 사용자가 전체 요청 반영 후 **v0.9.0-beta.1** 발행을 명시했습니다.
이 지시는 이전 0.8.x 유지 및 발행 대기 지침보다 우선합니다. 새 태그를 만들고 기존 태그는 덮어쓰지 않습니다.
릴리즈 노트에는 이전 베타를 포함한 누적 변경과 검증/운영 대기를 구분합니다.
Worker 배포·D1 변경은 이 직접 수신기 배포에 필요하지 않습니다.
