## 운영 기록

HA SSH에서 DB를 읽기 전용으로 열고 설치된 archive_codec.loads로 복원했다. 운영 데이터·토큰·위치 원문은 저장소로 복사하지 않았다.

한국 시간 15:32~15:34 충전 요약: 0.15kWh, 119.9737초, 추정 42원. 상태 기록에서 15:32:36에는 21,100Wh와 charging=false, 15:33:37에는 21,250Wh와 false, 15:34:37에는 21,250Wh와 true 및 4,501W, 15:36:39에는 21,250Wh와 true 및 0W가 확인됐다. 전력은 에너지 차분 추정이며 실측 충전기 전력이 아니다. 사용자는 실제 충전하지 않았다고 설명했다.

검사 시 HA 설치 버전은 beta.3이었다. 상태 데이터에 실행 중인 Comma 커밋 정보가 없어서 기기 설치 버전은 확정하지 않았다. 아래 재현은 과거/현재 저장소 소스에 대한 검증이며 기기 실행 버전 확인을 대신하지 않는다.

## 최종 beta.5: 영구 삭제와 그래프 정정

사용자는 beta.4를 사용 중이며 beta.5 설치 전에 기존 제외·복원 UI를 스와이프 삭제 방식으로 교체해 달라고 요청했다. 로컬의 beta.6 계획은 발행하지 않고 beta.5를 수정했다.

오른쪽 스와이프 또는 PC 드래그/우클릭/Delete 키로 삭제 버튼을 노출한다. 영구 삭제·복원 불가 확인 후에만 관리자 WS가 HA 원본 charge 이벤트·요약·결제·그룹 연결을 트랜잭션으로 삭제한다. cloud 재수신은 삭제 ID로 차단한다. 최소 시간·에너지·추정 비용 정보는 그래프/월간 원장 정정용으로 보관하며 결제 금액이나 전체 원본을 복원하는 API는 없다. 병합 기록은 전체 삭제한다. 다른 차량/이전 버전/변경된 그룹은 거부한다.

그래프는 삭제한 세션 시작~끝+300초의 충전 플래그를 표시에서 억제한다. 겹치는 정상 세션은 유지한다. SOC·유효 샘플·수집 시간·사용량·주행 시간은 보존한다. 삭제 시 archive.revision을 변경해 공유 그래프 캐시를 무효화하고 live 값을 먼저 갱신한 뒤 로컬 그래프를 다시 읽는다. cloud 쿼리는 추가하지 않는다.

클라우드/Comma 원본과 HA recorder 상태 이력을 삭제하지 않는다. 운영 데이터에 실제 삭제를 실행하지 않았다. 현장 설치/최종 확인은 HACS 업데이트 후 필요하다.

## 검증

과거 세 커밋 및 현재 수집기에서 150Wh 한 창 오인을 재현했고, 동일 세션 회복 중복분은 10월 3일 수정부터 제거됐다. 실제 단가·0원·0kWh·추정 복귀, 삭제·원본 charge 제거·결제 제거·재수신/재시작 방지·관리자 권한·버전 충돌·월간 표시 보정을 검사했다. 그래프 charge_s=0/충전 마크 제거·SOC 유지와 인접 정상 충전 보존을 확인했다. Chromium에서 한국어/영어·모바일/데스크톱·밝은/어두운 테마의 스와이프/취소/삭제·비동기 스크롤/포커스 유지 검사를 수행했다.
