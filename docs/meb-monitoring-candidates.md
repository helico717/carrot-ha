# MEB 모니터링 데이터 후보 조사 — 2026-10-04

## 근거와 한계

사용자가 제시한 12V SOC OBD 표시를 출발점으로 조사했다. 아래 공개 목록은 방송 CAN DBC가 아닌 대부분 UDS ReadDataByIdentifier(서비스 0x22) 요청/응답 정의다. CAN에서 이미 방송되는 값이라고 취급하면 안 된다. 실제 Comma 버스에서 진단 ECU 접근이 가능한지, ISO-TP 응답 복원과 Panda 송신 허용 여부가 확인되지 않았다. 이번 beta.3에 UDS 기능이나 12V SOC 센서를 넣지 않았다.

- spot2000 원본(ID.3 기반): https://github.com/spot2000/Volkswagen-MEB-EV-CAN-parameters/blob/main/VW%20MEB%20UDS%20PIDs%20list.csv
- 2021 ID.4 실측 개발자 보고: https://cellpulse.app/blog/meb-soh-atsp6

## 12V SOC

ECU 0x710, DID 0x2AF7. 원본 목록에는 12V voltage와 SOC가 같은 multiframe 응답에 포함되며 SOC 식은 equation missing으로 표시된다. CellPulse는 0x710 / 응답 0x77A의 11-bit 진단 경로에서 2AF7에 12V 전압, SOC, 용량 등 11개 값을 읽었다고 보고한다. 이 보고는 접근 가능성의 근거이지 사용자 차량의 디코딩/접근 검증이 아니다. 로컬 vw_meb DBC에서 12V SOC 방송 신호는 찾지 못했다. 전압만으로 SOC를 만들어내지 않는다.

필요한 다음 검증: 사용 중인 OBD 앱/어댑터 및 차량 프로필 확인 -> 2AF7 원시 응답과 앱 SOC를 같은 시각에 비교 -> 반복 값에서 byte 위치/배율/무효값 확정 -> Comma 연결 경로에서 접근 가능성 검토. 외부 OBD 진단기가 연결돼 있을 때 응답을 수동 수신할 수 있는지는 별도 버스 실측이 필요하다.

## 우선순위 후보

| 후보 | DID | 활용 | 준비 상태 |
| --- | --- | --- | --- |
| 운행/AC/DC 충전 모드 | 7448 (BMS) | 잔량 변동 오탐 보완 | 공개 목록에 정의, 실차 응답 필요 |
| HV 배터리 전류 + 전압 | 1E3D + 1E3B | 잔량 미분 대신 전력 측정, 회생 구분 | 전류 수식에 byte shift 의심 오류가 있어 그대로 구현 금지 |
| 배터리 대표·최저·최고 온도 | 2A0B, 1E0F, 1E0E | 온도와 충전 속도 상관 확인 | 응답 DID/길이 표기 일부 불일치, 원시 응답 확인 필요 |
| 셀 전압 최저·최고 및 편차 | 개별 1E40 이후, 극값 셀 번호 1E33/1E34 | 셀 균형 추세, 상세 진단 | 목록의 극값 항목은 셀 번호; 실제 전압은 해당 셀 조회 또는 전체 스캔 필요 |
| 충전 허용 전류 | 1E1B | BMS 충전 제한과 충전기 측 제한 구분 보조 | 충전기 출력 보장 값이 아님 |
| 12V SOC/전압 | 2AF7 (0x710) | 보조배터리 상태 추세 | SOC 식/원시 응답 검증 필요 |
| DC-DC 전류/전압 | 465B / 465D (DC-DC ECU) | 12V 공급 동작 확인 | DC-DC 출력과 12V 배터리 순충전 전류는 구별 |
| 냉각수 입·출구 온도/펌프/PTC 전류 | 189D / 743B / 1620 | 배터리 열관리 동작 관찰 | 차량별 확인 필요 |
| 누적 충전/방전 에너지 | 1E32 | 장기 에너지 사용 추세 | 회생 포함 여부·카운터 의미 확인, 유료 충전량으로 바로 대체 금지 |

차계부에 필요한 우선순위는 충전 모드 + 실제 HV 전류, 12V SOC, 배터리 온도다. 셀 전체/누적값은 필요할 때 상세 진단으로 조회하는 것이 요청 수와 저장량을 줄인다. 신호·수식 확인 전에 경고 임계값이나 SOH/잔여수명 결론을 만들지 않는다.
