## 발견 사항

1. **P1 — 복귀 스크립트의 주차 확인 실패 시 진행.** `compat/iqpilot/switch_to_carrot.sh:14`는 IsOnroad가 정확히 1일 때만 거절한다. Params가 없거나 읽히지 않으면 checkout을 허용한다. 기존 SwitchScriptTests의 로컬 Git fixture에서 IsOnroad를 삭제해 실행했으며 종료 코드 0, 당근 커밋으로 전환됨을 확인했다. 부팅 중 상태가 아직 없거나 진단이 불가능한 상태에서도 소스를 교체할 수 있다. 명시적인 IsOffroad=1 및 IsOnroad=0을 모두 확인하고, 누락·오류·불명 값에는 변경 전에 중단해야 한다. 해당 회귀 시험이 필요하다.
2. **P2 — 로고 화면으로 설치된 OS를 단정.** `docs/IQPILOT_HA_INSTALL_AND_RETURN.md:109`는 첫 부팅에서 1시간 넘게 로고/오류가 나면 “아직 당근 OS 상태(IQ.OS 기록 실패)”라고 설명한다. IQ.OS 설치 후 실행 단계의 장애도 같은 화면을 만들 수 있으므로 화면과 시간만으로 OS 기록 실패를 판단할 수 없다. OS·슬롯 확인 전에는 상태 미확인으로 안내하고 실제 상태에 맞춰 복구 경로를 결정해야 한다.
