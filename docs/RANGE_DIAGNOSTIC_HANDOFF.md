## 승인 및 구현 상태

이전 구현 시도에서 차량 제어 프로세스와 Panda 안전 정책에 고정 읽기 예외를 추가하는 쓰기 요청이 자동 승인 심사에서 차단됐다. 사용자는 영향 설명과 일시정지를 요청한 뒤, 최종적으로 추후 탐구 항목으로 남기기로 했다. 안전 정책 변경은 승인되지 않았으며 현재 승인 요청이나 구현을 진행하지 않는다.

제안 범위는 bus1의0x710 DID2AB6 읽기1회와 필요한 ISO-TP 흐름제어, P/정지/제어 해제/신선도 확인, 제한 시간과 쿨다운, 자동 재시도/다른 버스 탐색 없음이다. 단일sendcan 송신자는 carD이므로 별도 프로세스가 같은 publisher나 USB/Panda 소유권을 차지하면 안 된다. 현재 MEB 정책은 이 송신을 허용하지 않는다. H7의 CAN-FD 자동 변환과 Classic CAN 진단 형식도 검토해야 한다.

Comma 실행 소스는 수정하지 않았다. `/private/tmp/range_diagnostic.py`는 미검증 초안이며 임시 파일의 영구 보존을 가정하지 않는다. 설치 스크립트 실행 요청은 심사 거부로 실행되지 않았다. 새 HA 버튼/결과 센서·명령 프로토콜은 미구현이다. 실제 CAN 송신/기기 업데이트/펌웨어 기록/재부팅 없음.
