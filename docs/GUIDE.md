# Carrot HA 통합 및 대시보드 종합 설명서

## 값과 시간 읽는 법

| 표시 | 의미 |
|---|---|
| 숫자 | 실측, 계산값 또는 저장된 마지막 값. 숫자가 보인다고 반드시 현재 실측은 아니다. |
| `0` | 실제 0 또는 계산·집계 기본값. 특히 월 충전 집계의 0은 데이터가 없을 때도 나타난다. |
| `—` | 화면이 표시할 수 있는 값이 없음. 0, 꺼짐, 충전 종료를 뜻하지 않는다. |
| `정보 없음` | 에어컨·주행 보조 등의 참/거짓을 판단할 값이 없음. |
| `unknown` | HA가 해당 엔터티 값을 알 수 없음. 화면에서는 정보 없음 등으로 번역될 수 있다. |
| `unavailable` | HA에서 엔터티를 사용할 수 없는 상태. 차량의 물리적인 전원 상태와 같지 않다. |
| `true / false / null` | 원본 JSON의 참 / 거짓 / 미확인. `null`을 거짓으로 해석하지 않는다. |
| `계산 중` | 내 차 탭에서 충전 완료 예상 시각을 만들 값이 없음. 잠시 기다린다고 반드시 계산되는 것은 아니다. |
| `기록 없음`·대기 문구 | 선택한 기간에 기록이 없거나 필요한 좌표·이력을 받지 못함. 해당 기간에 운행이 전혀 없었다는 증거는 아니다. |

### 서로 다른 시각

| 필드·화면 문구 | 의미 |
|---|---|
| `measured_at` / 차량 측정 시각 / 하단 차량 정보 수신 | 차량 값의 측정 시각. 현재 수집기는 배터리 에너지 측정 시각을 우선 사용한다. 하단의 ‘수신’ 문구도 이 필드를 표시한다. |
| `field_measured_at` | 항목별 마지막 측정 시각. 배터리는 최신이어도 공조·GPS 등은 오래됐을 수 있다. |
| `last_received` | 최신 상태 이벤트의 `observed_at`. 현재 클라우드 경로에서는 장치 보고의 시각이며, 서버가 수신한 순간을 독립적으로 측정한 시각은 아니다. |
| `last_sync` / HA 업데이트 | HA가 클라우드 동기화를 성공적으로 완료한 시각. 차량 값이 최신이라는 보장은 없다. |
| `parking_at` | 마지막 주차 좌표의 기록 시각. 문 잠금·하차 시각이 아니다. |
| `measurement_age_s` | 차량 측정 시각으로부터 경과한 초. HA 값 계산 시 산출되며 연속 초시계는 아니다. |

현재 기본 주기는 CAN 샘플링 약 30초, 장치 보고 주행 30초·주차/충전 60초, HA 클라우드 동기화 60초, 표시 중인 대시보드 자동 조회 60초다. 주행 상태 변경 시 추가 보고가 있다. 처리·통신 지연 및 브라우저 비활성 상태에 따라 화면 반영은 더 늦을 수 있다. 새로고침은 차량에 CAN 송신을 요청하거나 차량을 깨우는 기능이 아니다.

## 우측 상단 상태 배지

연결 판정이 최우선이고, 연결이 확인되면 차량 상태를 **충전중**, **주행 중**, **주차중**으로 명확하고 단순하게 표시한다. 충전 중 키 ON(IGN ON / 에어컨 가동 등)으로 `onroad` 신호가 전달되더라도 충전 중인 상태가 유지되며 '주행 중'으로 오인식되지 않는다. 또한 주차 중에는 데이터 경과 시간이 계속 늘어나는 문구 대신 안정적으로 '주차중'을 표시한다.

| 표시 문구 | 색상 계열 | 판정·의미 |
|---|---|---|
| **충전중** | 초록 | 연결 정상, 충전 추정 참. 충전 중에는 키 ON 상태여도 주행 중으로 덮어쓰이지 않는다. (실제 차속 발생 시 제외) |
| **주행 중** | 파랑 | 연결 정상, 주행 상태 참. D 기어의 신호 대기 등 실제 속도 0인 경우도 포함한다. |
| **주차중** | 회색 | 연결 정상, 주행 상태 거짓이고 충전 추정이 참이 아님. 주차 중 측정 시각 경과와 상관없이 주차 상태를 유지한다. |
| **오프라인** | 노랑·황갈색 | HA 클라우드 조회 상태가 유효한데 최신 장치 보고가 300초 이상 지남. 전원 꺼짐·통신 단절·수집 중단 등을 이 문구만으로 구분할 수 없다. |
| **연결 확인 중** | 노랑·황갈색 | 연결 엔터티가 `on`/`off`로 확정되지 않음. 초기 로딩, HA 클라우드 오류, 오래된 HA 동기화, 엔터티 설정 문제 등이 가능하다. |
| **상태 확인 중** | 노랑·황갈색 | 연결은 확인되지만 주행·주차·충전을 분류할 값이 부족함. |

### 색상 상세

작은 점은 글자와 같은 색이다. 경고색은 고장 확정이 아니라 현재 상태를 확신할 수 없음을 뜻한다.

| 구분 | 어두운 테마: 배경 / 글자 | 밝은 테마: 배경 / 글자 |
|---|---|---|
| 주행 | `#133960` / `#83bdff` (파랑) | `#e0edff` / `#1356a2` |
| 충전 | `#173e29` / `#83e2a4` (초록) | `#e2f2e7` / `#156332` |
| 주차 | `#363b40` / `#e0e3e5` (회색) | `#e4e7e9` / `#4b555b` |
| 오래됨·오프라인·미확인 | `#49391e` / `#ffdc91` (황갈색·노랑) | `#fff1bd` / `#745400` |

### 오래됨·연결 판정 기준

- 수집기는 배터리 측정 후 **120초 초과** 시 `stale=true`를 보고한다. HA는 이를 유지하며 자체 측정 경과가 **180초 초과**여도 오래됨으로 판정한다. 따라서 3분을 기다리지 않고도 오래됨이 될 수 있다.
- 클라우드 상태가 `ok` 또는 `syncing`이고 HA 마지막 성공 동기화가 180초 이내여야 장치 연결을 판단한다. 이후 장치 보고가 300초 미만이면 연결, 이상이면 오프라인이다. 시각이 없거나 유효하지 않으면 미확인이다.
- 배지의 연결 판정은 기본 `comma_online` 엔터티 기준이다. 카드의 `online_entity`를 다른 엔터티로 바꾸면 그 엔터티 상태를 따른다.
- 정상적인 주차에서도 `주차중 → 마지막 확인: 주차 · 측정 N분 전 → 새 측정 후 주차중`으로 바뀔 수 있다. 차량 절전인지 수신 경로 문제인지는 배지만으로 확정할 수 없다.

## 대시보드 탭

### 내 차

- 우측 상단 배지와 큰 차량 상태 문구는 같은 판정을 사용한다.
- 배터리 잔량은 0~100%로 표시한다. 비충전 상태에서 **30% 미만은 주황, 15% 미만은 빨강**으로 강조한다. 15%는 주황, 30%는 일반 표시다.
- 최신 상태가 충전일 때 충전 애니메이션·추정 전력·100% 예상 완료 시각·80/100% 목표 표시를 보여준다. 80% 이상에서는 80% 목표 표시를 숨긴다.
- 최신 상태가 주행일 때 주행 애니메이션을 보여준다. 오래됨·오프라인·미확인에서는 내 차 탭의 실시간 주행/충전 애니메이션을 켜지 않는다. 숫자는 마지막 값으로 남을 수 있다.
- 충전 시 빠른 정보: 추정 충전 전력, 예상 완료시간, 총 주행거리, 이번 달 충전량. 그 외: 총 주행거리, 이번 달 주행, 이번 달 충전량·추정 요금. 좁은 화면에서는 일부 타일이 숨겨질 수 있다.
- 외기·12V 전압·공조 ON/OFF는 최신 전달값이다. 항목별 측정 시각은 서로 다를 수 있다.
- 주차 위치·최근 주행 바로가기는 저장된 좌표·이력을 연다. 정보가 없으면 위치 수신 대기·최근 주행 없음 등의 문구가 나온다.

**11kW 경계의 현재 차이:** 내 차 탭의 ‘고속충전중…’은 표시 전력 **11kW 이상**, 월 집계·충전 기록의 급속 분류는 **11kW 초과**다. 정확히 11kW에서는 표현이 다를 수 있다. 급속/완속은 충전기 종류 직접 감지가 아니다.

### 주행

최근 7일 날짜별 횟수와 주행 목록을 보여준다. 날짜를 선택하고 주행을 누르면 다음을 확인한다.

| 항목 | 의미 |
|---|---|
| 주행거리 | 기록된 GPS 경로 기반 거리. 차량 계기판의 누적거리와 다를 수 있다. |
| 주행시간 | 기록된 주행 시간. 수집 공백이 제외될 수 있으므로 출발~도착의 벽시계 시간과 다를 수 있다. |
| 평균속도 | 기록 거리 ÷ 기록 시간. |
| 최고속도 | 보관된 경로 좌표에 포함된 GPS 속도의 최댓값. |
| 출발·도착 시각 | 저장된 세션 시작·종료 시각. |
| 경로 좌표 수 | 보관된 좌표 개수. 원래의 모든 CAN/GPS 샘플 수가 아니다. |
| 경로 색 | 저속 주황/빨강 → 노랑 → 고속 초록. 해당 경로의 최고속도를 기준으로 상대적으로 표현하며 제한속도 준수 여부가 아니다. 속도 미상 구간은 회색일 수 있다. |
| 출발·도착 마커 | 큰 지도에는 ‘출’·‘도’ 표시(초록·주황). 내 차의 작은 경로 지도는 출발 하늘색·도착 파랑이다. |

일부 캡션은 큰 지도에서도 ‘출발 하늘색 / 도착 파랑’으로 남아 있어 실제 큰 지도 색과 다르다. ‘출’·‘도’ 글자로 구분한다. 미선택 시 요약·주차 위치를 표시할 수 있다. 빈 날짜는 저장된 주행이 없다는 뜻이다.

현재 수집기는 100m 이상이고 경로가 2점 이상인 주행을 기록한다. GPS 점은 주행 중 최소 약 5초 간격으로 취하며, 긴 공백·비정상 이동을 제외한다. 경로가 길어지면 점을 줄이므로 세밀한 이동이 생략될 수 있다.

### 위치

- 주행 상태이면 차량 위치, 그 외에는 마지막 주차 위치를 표시한다. 차량 좌표가 없으면 주차 좌표를 대신 사용할 수 있다.
- 위도·경도는 소수점 다섯 자리로 보여주지만 실제 정확도가 그만큼 높다는 뜻은 아니다.
- ‘주차중 · … 경과’는 `parking_at`부터 현재 시각(벽시계 시간)까지의 실제 주차 경과 시간을 계산하여 보여준다. (차량 통신 종료 후에도 주차 경과 시간이 멈추지 않고 실시간으로 반영된다.)
- 위치가 없으면 ‘위치 정보 대기 중’, ‘유효한 위치 좌표를 기다리고 있습니다’가 나온다. 지도 다운로드 실패는 CAN/GPS 고장과 별개의 문제다.
- 타일은 배터리 잔량, 총 주행거리, 외기온, 주행 시 속도/비주행 시 12V 전압을 표시한다.

**현재 표현의 한계:** 위치 탭의 ‘주행 중 (실시간)’ 칩은 우측 상단 배지와 달리 `onroad` 값만 본다. 오래된 데이터에도 남을 수 있으므로 상단 배지와 측정 시각을 우선한다. ‘실시간 계기판 속도’라는 보조 문구와 달리 현재 속도 값은 GPS에서 계산한다.

12V 보조 문구는 단순 임계값이다. **12.0V 미만 ‘주의 · 저전압 경고’, 12.0V 이상~12.4V 미만 ‘보통 · 전압 안정’, 12.4V 이상 ‘정상 · 방전 위험 없음’**이다. 전압만으로 배터리 건강이나 방전 위험을 보장할 수 없다. 값이 없어도 기본 ‘정상’ 문구가 남을 수 있으므로 숫자가 `—`이면 판단하지 않는다.

### 충전

월 충전량·추정 요금·완속/급속 분류 충전량, 최근 7일 충전 기록, 배터리 사용량 그래프를 제공한다.

| 기록 표시 | 의미 |
|---|---|
| 완속 / 급속 | 기록 에너지 ÷ 기록 시간으로 구한 평균 전력 11kW 이하 / 초과. 월 집계는 개별 측정 구간 전력으로 나누므로 세션 전체 분류와 합계가 꼭 일치하지 않는다. |
| kWh | 배터리에 증가한 것으로 관측된 에너지. 충전기 계량값·전력망 사용량·손실 포함 전력량과 다르다. |
| 기록된 충전량 | 저장된 세션 값이며 실제 전체 충전량을 보장하지 않는다. |
| 일부 구간만 수집 | `partial=true`. 재시작·누락 등으로 세션 일부만 기록됐을 수 있다. |
| N회 병합 / N분 간격 재연결 | 가까운 충전 기록을 화면에서 묶음. 기본 간격은 -60초~900초이며 시간상 근접성으로 묶는 것이므로 물리적으로 플러그를 재연결했다는 증거가 아니다. 합산 시간은 각 세션 시간의 합으로, 사이 공백은 포함하지 않는다. |

월 추정 요금은 현재 수집기 기준 완속 280원/kWh, 급속 320원/kWh의 고정 단가다. 계약·할인·충전 사업자 청구서와 다를 수 있다. 충전 진행 중 배지와 종료되어 저장된 기록은 반영 시점이 다르다.

#### 배터리 사용량 그래프

- 일별 사용량(%)은 유효한 연속 측정 간 **SOC 감소분의 합**이다. 충전 증가분과 상계한 순감소량이 아니다. 재충전 후 다시 사용하면 하루 100%를 넘을 수 있다.
- 일별 선택 막대는 파랑, 100% 초과는 노랑 계열이며 미선택은 회색이다. `—`는 계산할 연속 관측이 부족한 경우다.
- 5분 초과 공백은 사용량에 연결하지 않는다. 오래된 샘플과 미래 시각 등 유효하지 않은 샘플은 제외한다.
- 시간별 막대는 그 시간대에 남은 대표 SOC(마지막 유효 샘플)다. 시간 평균이나 한 시간 내내 유지된 SOC가 아니다.
- 시간별 **파랑은 주행, 회색은 주차 또는 마지막 확인값, 초록은 해당 시간에 충전 관측/기록이 있음**을 뜻한다. 비충전 막대는 30% 미만 주황·15% 미만 빨강이 우선한다.
- 마지막 SOC를 측정 없는 이후 시간대로 이어 표시할 수 있다. 이 값은 새 실측이 아니며 사용량 계산에 넣지 않는다. 툴팁의 ‘마지막 확인값’을 확인한다.
- 초록 배경·번개는 한 시간 내내 충전했다는 의미가 아니다. SOC가 없어도 충전 세션이 있으면 충전 배경만 나올 수 있다. 빈 구간은 표시할 값이 없음이다.
- ‘수신 N건’은 저장된 상태 이벤트 수, ‘유효 SOC N건’은 검증을 통과한 SOC 레코드 수, ‘오래된 값 N건’은 수신 기록 중 오래됨 플래그가 있는 수다. 서로 같은 의미가 아니며 유효 건수가 모두 고유 측정이라는 보장도 없다.
- ‘수집된 구간’은 유효한 연속 측정으로 연결 가능한 시간의 합이다. 하루 전체·장치 가동 시간과 다르다.
- ‘기록된 주행/충전 시간’은 저장된 세션 시작~종료 구간을 사용하고 중복 구간은 합친다. 진행 중이거나 누락된 세션은 빠질 수 있다.
- ‘시간별 기록을 불러올 수 없습니다’는 그래프 데이터가 없다는 뜻이다. 통합과 프런트엔드 버전도 함께 확인한다.

### 상태

배터리·전력, 주행·운행 기록, 공조·실내 환경을 모아 보여준다. 각 숫자의 정의는 아래 엔터티 표와 같다. 충전 남은시간·완료시각 행은 `charging`이 참일 때 표시한다.

에어컨은 **작동(초록) / 꺼짐(회색) / 정보 없음(옅은 회색)**, 주행 보조는 **활성(초록) / 비활성(회색) / 정보 없음(옅은 회색)**이다. 상태 탭의 개별 값·충전 행은 오래됨 여부로 모두 숨겨지지 않는다. 현재값인지 확인할 때 상단 배지와 항목별 측정 시각을 함께 본다.

‘수신 데이터 전체 보기’는 HA가 가공·집계한 현재 값의 JSON이다. CAN 원시 프레임 덤프가 아니다. 모두 복사는 ‘복사 완료!’ 또는 ‘복사 실패’로 결과를 표시한다.

## 충전 판정과 예상 시간

### 충전은 추정값

1. 주차로 판단된 상태에서 배터리 에너지의 **90~240초 구간** 증가를 비교한다.
2. 구간 추정 전력이 **300~250,000W** 범위인지 검사한다.
3. 한 구간 **100Wh 이상 증가**, 또는 연속 양의 증가 구간 최소 2개에서 **합계 50Wh 이상**이면 충전으로 확정한다.
4. 확정 전에는 후보로만 유지한다. 이때 전력 추정은 양수여도 충전 엔터티는 아직 꺼짐일 수 있다.
5. 확정 세션은 짧은 정체를 허용하되, 적격 증가 없이 300초 경과하거나 주행으로 전환하면 끝낸다. 측정이 120초보다 오래되면 충전·전력은 미확인으로 비울 수 있다.

작은 실제 충전은 확인이 늦을 수 있고, 반복되는 BMS 에너지 보정은 오인식을 만들 수 있다. `charging=false`는 코드가 충전을 확인하지 않았다는 뜻이며 플러그 분리를 증명하지 않는다. `charging=null`은 미확인이다.

주행 판단은 최근 유효한 `carState`의 속도·기어를 사용한다. 속도 0.1m/s 초과는 주행, 그 이하의 P는 주차, D/R 등 주행 기어는 정차해도 주행으로 본다. N은 진행 중인 주행이 있으면 유지한다. 신호가 없고 콤마 `IsOnroad=false`이면 주차, `IsOnroad=true`인데 신호가 없거나 모호하면 미확인이다. 자세한 기준은 [주행·충전 구분](CHARGING-MOTION.md)을 참고한다.

### 충전 시간·완료시각

남은 시간은 `max(0, 목표 에너지 − 현재 에너지) ÷ 현재 추정 전력`이다. 목표 용량에는 BMS 용량 추정을 우선하고 없으면 SOC 계산 용량을 쓴다. 표시 SOC의 분모와 달라 80% 표시와 80% ETA가 완전히 일치하지 않을 수 있다.

- 목표는 80%, 100% 두 개다. 목표 에너지에 이미 도달하면 0초로 계산한다.
- 전력 300W 미만 또는 필요한 값이 없으면 시간·완료시각은 미확인이다.
- 차량의 목표 충전 설정, 예약, 충전 후반 출력 감소, 온도, 충전 손실을 반영한 실제 예약 시각이 아니다.
- 일반 대시보드의 ETA는 현재 전력이 유지된다는 단순 추정이다. 디버그 화면의 충전 곡선 시뮬레이션과 구분한다.
- 이 계산 자체에는 모든 오래됨 조건이 반영되어 있지 않다. 오래된 전력이 남으면 계산값도 남을 수 있으므로 신선도 확인이 우선이다.

| `last_trip_at` | 최근 주행 종료 | 없음 | 최신 주행 이벤트 observed_at을 표시한다. 정상 기록에서는 종료 시각에 대응하지만 별도 수신/가져오기 자료에서는 의미를 확인해야 한다. |
| `parking_at` | 주차 위치 기록 시각 | 없음 | 마지막 주차 좌표 기록 시각. 주차 GPS 또는 최근 주행 끝점에서 가져오며 문 잠금 시각이 아니다. |
| `measured_at` | 차량 측정 시각 | 없음 | 전체 차량 데이터의 대표 측정 시각. 항목별 시각과 다를 수 있다. 없으면 이벤트 시각을 대신 사용할 수 있다. |
| `last_sync` | HA 동기화 시각 | 없음 | HA의 마지막 클라우드 동기화 성공 시각. 갱신됐어도 차량 측정이 멈춰 있을 수 있다. |
| `measurement_age_s` | 차량 데이터 경과시간 | s | 대표 측정 시각 경과 초. 계산 시 음수는 0으로 제한. 측정 시각 파싱 실패 시 값이 없을 수 있다. |
| `cloud_status` | 클라우드 연결 상태 | 없음 | not_configured / syncing / ok / HTTP_상태코드 / error. 아래 연결 상세 표 참고. |

현재 등록되는 일반 센서는 **40개**다. 표의 단위는 HA 기준이며 대시보드에서는 초를 시간·분으로, KRW를 원으로 표시한다.

### 클라우드 연결 상태 값

| 값 | 의미 |
|---|---|
| `not_configured` | 상태값이 아직 설정되지 않았을 때의 기본 표시. Worker 주소·읽기 토큰 설정을 확인한다. 초기화 중에도 가능하다. |
| `syncing` | HA가 동기화 작업을 수행 중. 성공 완료를 뜻하지 않는다. |
| `ok` | 최근 동기화 성공. 차량 측정이 최신이라는 뜻은 아니다. |
| `HTTP_401`, `HTTP_403` 등 `HTTP_<숫자>` | 클라우드 요청이 HTTP 오류로 끝남. 401/403이면 인증·권한·서버 설정을 확인한다. 특정 코드만 발생하도록 제한되어 있지 않다. |
| `error` | HTTP 상태 오류 이외의 동기화 실패. 네트워크·응답 형식 등의 원인은 HA 로그에서 구분한다. |

## 이진 센서 전체 목록

일반 플래그는 원본 값이 있으면 `on`/`off`, 없으면 `unknown`이다. HA UI는 장치 클래스에 따라 연결됨/연결 끊김, 문제 감지 등의 표현을 사용할 수 있다. 아래 의미는 신선도와 별개이므로 `stale`도 함께 확인한다.

| 키 | HA 이름 | on | off / 미확인 |
|---|---|---|---|
| `onroad` | 주행 모드 | 주행으로 판정 | off: 주차 판정. unknown: 주행/주차 판단 불가. 최신 데이터에서는 `driving`을 사용하고 이전 자료는 `onroad`를 사용한다. |
| `charging` | 충전 중 추정 | 에너지 증가 검증으로 충전 세션 확인 | off: 충전 확인 안 됨. unknown: 측정 오래됨·판정 불가 등. 플러그 연결 여부와 일치하지 않을 수 있다. |
| `ac_on` | 에어컨 작동 | 에어컨 스위치 신호 참 | off: 신호 거짓. unknown: 미수신. 컴프레서 실제 전력 소비를 측정한 값이 아니다. |
| `stale` | 차량 데이터 오래됨 | 수집기 오래됨 또는 HA 기준 측정 180초 초과/시각 오류 | off: 전체 오래됨 조건에 해당하지 않음. 모든 개별 항목이 최신이라는 보장은 없다. |
| `enabled` | 주행 보조 활성 | 최근 selfdriveState의 enabled 참 | off: enabled 거짓. unknown: 유효한 최신 신호 없음. 차량 운행/시동 상태 자체가 아니다. |
| `comma_online` | 콤마 연결 상태 | 최근 장치 보고 및 HA 동기화 확인 | off: 조회는 정상이나 장치 보고 300초 이상 경과. unknown: 클라우드 조회·시각 문제로 판단 불가. |
| `emergency_charging` | 비상 충전 모드 추정 | 충전 추정 참, 전력 1.5kW 이하가 300초 이상 이어지고 데이터가 오래되지 않음 | off: 조건 미충족·정보 부족·오래됨 등을 포함. 정상 충전을 보증하지 않는다. |

비상 충전은 **저전력 패턴 추정**이다. 낮은 설정 전류·정상적인 출력 제한에서도 켜질 수 있으며 커넥터 접촉 불량을 직접 진단하지 않는다. 문제 장치 클래스이므로 HA에서는 on이 문제 감지로 보일 수 있다. 속성 `low_power_duration_s`는 추정 지속 초, `threshold_kw=1.5`, `min_duration_s=300`, `charge_power_kw`는 판정 전력이다.

### 콤마 연결 상태의 상세 속성

| 속성·값 | 설명 |
|---|---|
| `last_telemetry_at` | 최신 상태 이벤트 시각 |
| `telemetry_age_seconds` | 해당 보고의 경과 초. 유효한 시각 없으면 null |
| `offline_after_seconds` | 현재 300초 |
| `reason=recent_telemetry` | 최근 보고 확인 |
| `reason=no_recent_telemetry` | 장치 보고가 300초 이상 오래됨 |
| `reason=cloud_unavailable` | 클라우드 상태 또는 HA 동기화가 유효하지 않아 판단 보류 |
| `reason=missing_or_invalid_device_timestamp` | 장치 보고 시각이 없거나 해석 불가/허용 범위를 벗어남 |

현재 구현은 60초 이내의 장치 미래 시각은 경과 0초로 취급하고, 그보다 큰 미래 시각은 연결 판단에 유효하지 않게 처리한다. 시계가 잘못되면 실제 통신 상태와 다른 표시가 나올 수 있다.

## 위치 엔터티

등록되는 GPS device_tracker는 두 개다.

| 키 | 이름 | 좌표 출처 |
|---|---|---|
| `vehicle_position` | 차량 위치 | 최신 전달 GPS의 위도·경도. 미수신 중에는 마지막 좌표가 남을 수 있다. |
| `parking_position` | 주차 위치 | 저장된 주차 좌표, 없으면 최근 주행 끝점 |

HA의 `home`, `not_home`, 사용자 정의 구역명은 이 좌표와 HA 구역 설정으로 결정한다. `home`은 시동 꺼짐, `not_home`은 주행 중을 뜻하지 않는다. 좌표가 없으면 위치가 미확인일 수 있다. 정확도에는 현재 GPS 정확도를 사용하며, 주차 위치도 같은 값을 사용하므로 주차 당시 정확도와 다를 수 있다. 미확인 정확도를 0으로 반환하는 경우가 있으므로 0m를 완벽한 위치 정확도로 해석하지 않는다.

## 원본 보기와 진단 속성

일반 센서·플래그의 공통 속성은 `measured_at`, `stale`, `field_measured_at`이다. 단, 연결 엔터티는 위의 전용 속성을 사용한다. `field_measured_at`는 엔터티 키로 찾으므로 `battery_kwh` 같은 변환 필드에는 비어 있을 수 있다. JSON의 원본 `field_measured_at.battery_wh`를 함께 확인한다.

SOC 엔터티에는 `nominal_net_kwh=78`, `nominal_gross_kwh=82`, `soc_capacity_kwh`, `soc_source=energy_based_calibration`이 추가된다. 앞의 78/82는 ID.4 참조 상수이며 모든 차량의 사양을 실측한 값이 아니다.

상태 탭 JSON에서 볼 수 있는 주요 추가 필드:

| 필드 | 가능한 값·의미 |
|---|---|
| `battery_wh`, `measured_capacity_wh`, `capacity_wh` | Wh 단위 원본/용량 값. 화면 kWh와 1,000배 차이가 있다. |
| `charge_power_w`, `charge_power_kw` | 내부 W와 화면용 kW. 단위 혼동에 주의한다. |
| `driving` | true/false/null. 기어·차속 기반 주행 판정. |
| `comma_onroad` | 콤마의 IsOnroad 모드. 실제 이동 여부와 다르다. |
| `gear` | park, drive, reverse, neutral, sport, low, eco, manumatic 등 전달된 기어 문자열 또는 null. 지원 범위 밖 값은 미확인 판정일 수 있다. |
| `wheel_speed_mps` | 차량 carState의 속도(m/s) 또는 null. 화면 GPS km/h와 다르다. |
| `gps` | latitude/longitude, speedMps, bearingDeg, accuracyM, measured_at 등 전달 좌표와 시각 |
| `parking`, `last_trip_parking` | 주차 좌표 또는 최근 주행 끝점 |
| `charge_months` | 월별 slow_kwh, fast_kwh, cost_krw 원장 |
| `charge_sessions` | 최근 충전 세션의 id, started_at, ended_at, energy_kwh, duration_s, partial 등 |
| `battery_history` | 날짜별 used, hours, charge_hours, drive_s, charge_s, covered_s 및 샘플 수. 그래프용 가공값 |
| `cloud_raw_state` | 제공된 클라우드 상태 원본을 보존한 중첩 데이터. HA 가공 결과와 같은 필드가 중복될 수 있다. |
| `entity_ids` | 카드가 참조하는 HA 엔터티 ID. 사용자가 변경한 ID에 따라 달라진다. |

JSON은 버전·차량·수신 자료에 따라 필드가 더 있거나 빠질 수 있다. 알 수 없는 정수 신호에 의미를 임의로 부여하지 않는다. 위치·장치 식별 정보가 들어갈 수 있으므로 공개 이슈에 전체 원본을 붙이기 전에 필요한 부분만 남긴다.

## 기록 범위와 자주 생기는 오해

- **상단 회색 주차중 = 차량 데이터가 영구적으로 최신**은 아니다. 수신이 멈추면 마지막 확인으로 바뀐다. 예전 버전은 오래됨을 배지에 반영하지 않아 같은 상황에서도 주차중으로 남았다.
- **초록 충전중 = 충전기 물리 연결 확인**이 아니다. 에너지 증가 추정이다. 오랫동안 하차해도 CAN 수신이 계속되는지는 해당 구간 실제 측정 시각으로 검증해야 한다.
- **오프라인 = 콤마 전원 꺼짐**은 아니다. 장치 보고가 없다는 의미다. HA가 클라우드에 접근하지 못하면 오프라인 대신 연결 확인 중이 될 수 있다.
- **마지막 확인: 주차 = 직전 충전이 종료됨**은 아니다. 오래된 충전 추정이 비워졌을 수 있다.
- **0kW = 플러그 분리**, **월 0kWh = 실제 충전 없음**, **빈 경로 = 주행 없음**도 성립하지 않는다.
- **BMS 용량 추정 = SOH**, **12V 정상 문구 = 방전 위험 없음 보증**이 아니다.
- **데이터 오래됨 off = GPS·열선까지 전부 최신**은 아니다. 개별 측정 시각을 확인한다.

HA 로컬 기록은 현재 기본값으로 상태 14일, 주행·충전 90일을 보관하고 14일보다 오래된 주행 경로는 좌표를 비워 요약만 남긴다. 하루 단위 정리와 주간 DB 압축이 있다. 화면의 최근 7일은 표시 범위이며 전체 보존 기간과 다르다. 보관 주행 횟수·거리 합은 정리로 줄어들 수 있다. 서버 보존 범위·가져온 기록에 따라서도 달라지며 누락된 CAN 측정을 복원할 수는 없다.

시간대도 주의한다. 수집기 충전 월 원장과 HA 월 충전 선택은 한국 시간 기준이며, 최근 7일 주행·충전 날짜 그룹과 배터리 그래프는 HA 시간대를 사용한다. 개별 시각 문자열의 화면 형식은 브라우저 로캘/시간대 영향을 받을 수 있어 해외 시간대에서는 월말·자정 근처 기록을 대조해야 한다.

## 설정과 관련 문서

- `device_id`: 통합과 수집기에 같은 장치 ID를 사용한다.
- `vehicle_name`: 카드 표시 이름. 실제 데이터나 차량 모델 판정을 바꾸지 않는다.
- `vehicle_image`: 차량 이미지 경로. 데이터 측정과 무관하다.
- `language: auto / ko / en`: HA 언어를 따르거나 한·영 화면을 고정한다. 엔터티 키·데이터 단위는 바꾸지 않는다.
- `online_entity`: 배지 연결 판정 엔터티를 재지정한다. 다른 목적의 이진 센서를 지정하면 배지가 오해를 줄 수 있다.
- `charging_entity`: 기존 카드 호환 설정이지만 0.5.3 내 차 탭 충전 애니메이션은 최신 차량 상태 판정을 사용한다. 이 설정만으로 오래된 값을 실시간 충전으로 바꾸지 않는다.
- 통합 옵션 `vehicle_model`, `soc_capacity_kwh`, `cloud_url`, `cloud_view_token`: 모델 표시·SOC 보정·연결 설정이다. 모델 이름만 바꿔 다른 차량 DBC가 지원되는 것은 아니다.

디버그/시뮬레이션 카드는 실제 차 상태와 구분한다. 시나리오로 만든 속도·SOC·충전 표시를 실제 수신 증거로 쓰지 않는다.
