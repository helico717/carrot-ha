# Carrot HA 0.6.9

## 수정

- 월간 전비를 동일한 유효 주행의 거리 합계 / 배터리 순소비량 합계로 계산합니다. 충전량을 분모로 사용하지 않습니다.
- 유효 주행 소비량과 전비 집계 거리 비율을 추가하고, 원본 상태 이력 정리 후에도 집계를 보존합니다.
- 추정 주행가능거리는 충분한 유효 주행 기록이 있을 때만 계산합니다. 임의 기본 전비 5.5는 제거했습니다.
- 이전 버전에서 HA Recorder에 저장한 전비 통계는 소급 수정하지 않습니다.

## 새 엔터티

- 도어 4개 및 트렁크 열림, 내부/외부 잠금 상태.
- BMS 하드웨어 모드, BMS 목표 SOC 신호, DC-DC 컨버터 온도.
- 하향/상향/미등/DRL/전후 안개등/후진등 요청.
- 콤마 CPU/GPU 온도, CPU/메모리 사용률, 저장공간 잔여율, 발열 상태, 네트워크 종류/신호 단계, 팬 목표 출력.
- 새 항목은 필드별 측정이 180초 이상 오래되면 미확인이 됩니다.

BMS 목표 SOC가 차량 UI 충전 상한과 같은지는 검증 전입니다. DC-DC 온도는 배터리 팩 온도가 아니며,
등화는 점등 요청, 팬은 목표 출력입니다. 후드 개폐/충전 플러그 체결은 신뢰할 수 있는 상시 상태 신호가 확인되지 않아 제공하지 않습니다.

## 업데이트

1. 콤마 수집기의 네 파일을 함께 업데이트합니다. [파일 목록 및 신호 의미](TELEMETRY-SIGNAL-REVIEW.md).
2. HACS에서 Carrot HA 저장소의 최신 main을 다시 다운로드하거나 업데이트합니다.
3. Home Assistant를 재시작합니다. 기존 통합을 삭제하거나 다시 등록할 필요가 없습니다.
4. 설정 → 기기 및 서비스 → Carrot HA → 차량 기기에서 새 엔터티를 확인합니다.
5. 기존 대시보드는 유지됩니다. 새 엔터티를 표시할 카드는 별도로 추가할 수 있습니다.

수동 설치 시 `custom_components/carrot_ha` 폴더 전체를 `/config/custom_components/carrot_ha`에 복사하고 재시작합니다.
HA 데이터베이스, 통합 설정, 토큰은 변경하지 않습니다.

## 검증 범위

HA/collector 단위·통합 테스트 80개 통과. Python 문법 및 diff 검사 통과.
사용자가 제공한 배포 후 출력에서 새 CAN 키 수신, collector 실행 및 Cloudflare 전송 성공을 확인했습니다.
실차의 각 문/잠금/등화와 값 대응, 목표 SOC 의미, 기기 헬스 수신 및 제어 성능 영향은 별도 검증이 필요합니다.
