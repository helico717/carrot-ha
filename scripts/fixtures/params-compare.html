두 화면을 불러오는 중입니다…

기존 — 현재 HA에 포함된 화면

기존 검색창과 검색 결과 전환·복귀 동작을 확인합니다.

신규 — 상위 최신 변경 + HA 연결 보완

간결한 검색창 · 검색 결과를 같은 화면에 표시 · 상세에서 검색 결과로 복귀

비교 방법
  1. 휴대폰 폭에서 ② → ③ → ④ 순서로 누르거나, 각 화면의 검색창과 항목을 직접 조작하세요.
  2. ②에서 검색창의 위치·디자인과 결과가 표시되는 위치를 비교하세요. ④에서 검색 결과로 돌아오는지 확인하세요.
  3. PC 폭에서는 두 화면이 넓어집니다. 가로로 스크롤해 비교할 수 있습니다.

모바일 키보드가 실제로 열리고 유지되는지는 휴대폰에서 확인해야 합니다. 이 프리뷰에서는 검색창 포커스·입력과 화면 이동을 확인할 수 있습니다.
