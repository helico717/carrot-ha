# 차계부 v0.8.13 사용 안내

## 설치·화면

HACS에서 0.8.13으로 업데이트한 뒤 HA를 재시작한다. agent는 업데이트/재시작 버튼을
대신 누르지 않는다. Worker/Comma 업데이트는 필요 없다.

재시작 후 HA 사이드바에 **차계부**가 자동으로 나타난다. 관리자 계정으로 클릭하면
기존 기록과 수동 입력 화면이 열린다. 기본 설치에는 별도 카드/리소스 등록이 필요 없다.

기존 Lovelace 안에 배치하고 싶은 경우에만 다음 선택 절차를 사용한다.
HA 설정 → 대시보드 → 리소스에서 아래를 JavaScript 모듈로 추가한다.

```text
/carrot_ha_static/carrot-vehicle-journal.js?v=0.8.13
```

리소스 메뉴가 안 보이면 사용자 프로필의 고급 모드를 켜서 확인한다.
새 카드에 다음 YAML을 넣거나 [전체 대시보드](dashboard.yaml)를 사용한다.

```yaml
type: custom:carrot-vehicle-journal
```

관리자 로그인으로 활성 통합 목록을 읽고 차량을 선택한다. entry_id를 설정하면 기본
차량을 고정할 수 있다. 기존 실시간 대시보드는 그대로 사용한다. 리소스 버전 URL은
후속 릴리즈 때 갱신한다. 자동 기록 갱신은 로컬 60초 주기이며 숨겨진 카드는 조회하지 않는다.

## 직접 기록

‘기록 남기기’에서 정비/지출, 누락 주행, 누락 충전을 고른다. 과거 날짜도 지원한다.
주행은 거리, 충전은 배터리 충전량을 입력하고 모르는 소비량·SOC·시각은 비운다.
충전량을 모르면 정비/지출 종류의 ‘충전비’로 비용만 기록할 수 있다.
금액 0원은 실제 무료 비용이고 빈 금액은 미확인이다. 세부작업에 타이어·와이퍼 등을
남길 수 있다. 시작·종료 시각을 생략한 수동 기록은 입력 날짜에 전량 귀속된다.

사진은 파일당 2MiB 이하 JPG/PNG/WEBP 최대 5장이다. 픽셀 재인코딩으로 EXIF 등
메타데이터를 제거한다. 큰 픽셀 이미지·재인코딩 후 제한 초과는 거절한다.
사진 저장 실패 시 기록 자체가 저장됐다는 안내를 보며, 사진은 다시 선택해 재시도한다.

차계부 탭에서 수동 기록을 수정·삭제·복원한다. 자동 기록은 이 카드에서 직접
수정하지 않는다. 자동 충전 실제 결제는 기존 충전 결제 화면을 사용한다.
같은 날 자동 기록이 있으면 중복 후보 경고를 확인한다. 실제 동일 주행/충전이면
수동 기록을 삭제해 중복 합산을 해소한다. 자동/수동 링크·필드 보정 UI는 후속 기능이다.

## 지표의 의미

월간 거리·충전량·비용은 관측된 기록 범위다. 전비는 에너지가 확인된 동일 구간
거리/에너지이며 전체 거리 커버리지를 표시한다. 수동 입력 소비량도 구분된 원장으로
포함될 수 있다. 일별 자정 배분은 시간 비례 추정이다. 주차 소비와 하루 전체 SOC는
아직 미확인으로 표시한다. 차량 상태는 최신 수신값이며 성공한 조회를 새 측정으로
취급하지 않는다. 과거 유가 이력 비교는 후속 기능이고 현재 HA 유가로만 비교한다.

## 저장·복구

HA config의 `carrot_ha/vehicle_journal/<entry_id>.sqlite3`에 저장한다.
사진은 같은 위치의 `<entry_id>/attachments/`에 둔다. 원장은 자동 만료하지 않는다.
초기 이관은 로컬 HA archive만 읽으며 삭제된 과거 raw는 복원하지 않는다.
로컬 outbox는 source 변경 transaction에 기록하고 target 집계 완료 뒤 ACK한다.
실패하면 원본 retention을 유예한다. 새 DB가 고장난 경우 기존 파일을 지우거나
재생성하지 말고 backup/상태를 진단한다. 실제 HA full backup의 DB·사진 포함/복원은
별도로 검증해야 한다.

개발 검증: `python3 -m unittest discover -s vehicle-journal/tests -v` (Pillow 필요),
`python3 vehicle-journal/schema/validate_schema.py`,
`NODE_PATH=<playwright package root> node vehicle-journal/tests/browser-check.cjs`.
