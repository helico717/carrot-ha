# 차량 등록·이관·설정·위치 관리

## 차량 추가

차계부의 차량 선택 목록에서 **새 차량 추가**를 선택한다. 차량 이름과 유종
(휘발유·경유·하이브리드·전기)을 입력한 뒤 다음 중 하나를 선택한다.

- **지금부터 기록할게요**: 기기·클라우드 토큰 없이 수동 차량을 생성한다.
- **마이클 데이터에서 불러오기**: 마이클 export XLS/XLSX를 선택하고 미리보기의
  건수·기간·금액·분류를 확인한 뒤 **이관 시작**을 누른다.
- **스냅샷에서 불러오기**: 차계부 전용 ZIP의 검증·미리보기 후 새 차량으로 복원한다.

마이클 XLS/XLSX는 20MiB, 차량별 스냅샷 ZIP은 128MiB까지 지원한다. ZIP의
압축 해제 총량은 256MiB로 제한한다. 큰 장기 사진 묶음의 스트리밍 백업은 후속 작업이다.
파일 오류 시 일부 기록만 저장하지 않는다. 미리보기는 관리자별 15분 유효하며,
완료 요청을 재시도해도 같은 차량을 두 번 만들지 않는다.

수동 원본의 주유 리터·단가·구간거리·연비·계기판 누적거리를 원본 정보로 보존한다.
확인되지 않은 거리를 계산해 주행 통계에 합산하지 않는다. 전기차 export 충전량도
배터리 실제 유입 에너지로 바꾸지 않는다. 기록 수정 창의 **마이클 이관 원본 정보**에서
읽을 수 있다. 원본 장소명은 위치로 보존하지만 좌표가 없으면 임의로 추정하지 않는다.
엑셀 export에 포함되지 않은 사진은 이관할 수 없다.

## 설정

차계부 최상단 오른쪽 **설정**에서 다음을 관리한다.

- 차량 이름·유종 수정, 휴지통 이동·복원. 기기 연동 차량의 연결은 유지한다.
- 차량별 스냅샷 다운로드 및 새 차량으로 복구.
- 카카오 JavaScript·REST API 키와 오피넷 일반 API 키 등록·교체·제거.
- HA 백업 통합의 현재 상태(요약 배너, 상태 뱃지, 일정/이력 그리드) 및 마지막 백업 관련 엔티티 표시.

휴지통은 DB·기록·사진을 지우지 않는다. 카카오 REST·오피넷 키는 서버의 HA
저장소에 두고 관리자 전용 설정 화면에서 현재 값을 확인·수정할 수 있다. 기본은 숨김이며 보기 버튼으로 표시한다. 저장·제거 전 확인을 받고 취소하면 요청하지 않는다. JavaScript 키는 웹 SDK용이다.
Native 키는 웹 차계부에 사용하지 않는다. 키는 Git·스냅샷에 포함하지 않는다.

Synology는 기존 HA 백업의 목적지다. 화면의 HA 백업 상태는 Home Assistant Core 백업 통합의 동작 상태를 표시하며, 차계부 전용 Synology NAS 자동 백업(일 7 · 주 4 · 월 12세대 보관 및 복원 검증)은 '백업 · 복구' 탭에서 관리할 수 있도록 안내 카드와 원클릭 탭 전환을 제공한다.

## 위치

상세 기록의 **수정**을 눌러 메모 아래 위치 영역을 연다. 위치가 없으면 지도 대신
**위치 추가**를 표시한다. 장소명 직접 입력, 장소 검색 결과 선택, 지도 클릭/터치로
핀 지정, **위치 제거**를 지원한다. 기록을 저장해야 변경이 확정된다.
원본 차량 수집은 수정하지 않고 차계부 내부 위치 보정으로 보존한다. 위치도 스냅샷에
포함하며, 삭제 보정은 원본 장소명을 자동으로 다시 표시하지 않게 한다.

카카오 개발자 사이트에서 앱의 **카카오맵 → 사용 설정 → 상태 ON**을 적용하고,
JavaScript 키의 SDK 도메인에 실제 HA 브라우저 주소의 origin(프로토콜·호스트·
기본이 아닌 포트)을 등록한다. `/carrot-journal` 경로는 붙이지 않는다.
검색 버튼을 눌렀을 때만 조회하며 서버 검색은 짧은 캐시와 요청 간격 제한을 적용한다.
대시보드의 주기 갱신 때문에 지도 검색·cloud 요청이 추가되지 않는다.

## 스냅샷 복구

전용 ZIP은 차량의 안정적인 UUID, 원장·요약·사진·위치·수동 보정·비교 설정 및
자동 충전 결제 원본 상태를 포함한다. 원본 결제는 삭제/제외 및 결제 그룹 정보도
보존한다. 고빈도 상태·상세 주행 경로·CAN·HA 전체 설정·인증 토큰은 제외한다.

같은 차량이 등록되어 있거나 휴지통에 있으면 복원을 중단한다. 기존 기록을 자동으로
덮어쓰거나 병합하지 않는다. 새 HA에서는 스냅샷으로 기록을 먼저 복원할 수 있다.
자동 차량을 다시 기기 연결하려면 인증 정보를 별도로 설정한다. 같은 기기 ID가
등록되면 안정적인 기존 차량 UUID와 결제 원본을 재연결하며, 기존 결제 원본과
충돌하면 덮어쓰지 않고 연결을 중단한다.

스냅샷은 ZIP 체크섬·사진 참조·스키마·외래키를 검증한 뒤 게시한다. 업로드 파일의
SQL을 실행하거나 ZIP 경로를 그대로 추출하지 않는다. 스키마 1→2 변경에는
검증된 이전 DB 백업을 먼저 만들고 기존 지출을 보존한 채 주유비 분류를 확장한다.

## 후속 기능 — 이번에는 미구현

- Synology로 전용 스냅샷 자동전송·세대 관리·NAS 보관본 검증.
- 현재 위치 권한으로 가까운 주유소 후보 선택, 오피넷으로 유종별 단가 제안.
- 누적거리 입력, 금액÷단가 추정 주유량 및 실제 리터 수정, 가득/부분 주유 기록.
- 이전 가득 주유부터 부분 주유를 포함한 연료량으로 연비 계산. 최초 구간/누락은 미확인.
- 지도 마커·거리/주소/유종별 가격·가까운/방문 장소 목록과 명시적인 지도 영역 재탐색.
- 영수증 OCR로 날짜·장소·단가·리터·금액 추출 후 사용자 확인·수정하여 저장.
