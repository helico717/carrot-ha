# 이전 디자인 대화의 사용자 요구사항 기록

출처: 사용자가 2026-10-06 이 채팅에 붙인 이전 대화 내용.
아래는 의미를 보존한 요구사항 정리이며, 전체 이전 대화나 원문 그대로의 전사본은 아니다.
현재 작업은 DB 기반 준비이며 이 문서의 '후보 구현'은 현재 실행 요청이 아니다.

## 역할·산출물

EV 인포그래픽 대시보드와 스마트 차계부를 기획하는 수석 프론트엔드/UI·UX 역할.
첨부 스타일의 다크 테마, 세련된 카드 그리드, 상단 세그먼트 탭을 계승하는
HTML/CSS/JS 기반 단일 인터랙티브 프로토타입, 서로 다른 후보 10개를 셀렉터로 비교.
데스크톱·모바일 반응형 지원. 후보는 아직 고르지 않았음.

## 스타일·내비게이션

친근하고 정중한 '~해요', '~했어요', '~에요' 문체. 다크 Bento Grid,
네온 블루·민트 포인트와 부드러운 전환. 상단 탭은 월간 요약, 주행 & 충전 통계,
유류비 절감 비교, 정비 & 소모품, 차량 상태.

## 기능

1. 월간 요약 좌측 상단 도넛: 충전비, 정비/소모품, 튜닝, 세차, 기타의 지출 비율.
2. 막대와 각 상단을 연결하는 추세선 복합 차트. 1일/1주일/1개월 기간 선택,
   충전 요금·정비 지출과 거리(km)·소비(kWh)·전비(km/kWh) 지표 전환.
3. HA 전국 평균 유가 센서(오피넷 등)를 기준가로 사용. 휘발유/경유/고급유 선택,
   비교 차량 공인연비(km/L) 직접 수정. 실제 월 주행거리·충전비와 내연기관 예상
   유류비 비교. 절약 문구, 게이지와 누적 비교 그래프.
4. 기록 모달: 카테고리(타이어, 와이퍼, 워셔액, 튜닝, 소모품 교체, 일반 정비,
   기타 등), 작업 날짜, 원 단위 금액, 사진과 미리보기, 메모/작업 내용.
   당시에는 HA Webhook/API에 JSON 전송·저장 구조를 요청했고 충전비 자동집계를 가정.
5. 실시간 배터리 잔량·도어·주행가능거리 등 차량 상태.

## 현재 계획과의 연결

장기 최소 일별 데이터로 주·월·연도 조회를 준비한다. 시간별 장기 보존은 제외.
수동 범위에 세차·보험·세금·주차·통행료와 주행/충전 누락 보완을 추가한다.
Webhook 자동화·장기 토큰·브라우저 저장 대신 인증된 HA 통합 내부 API를 준비한다.
현재 차량 수집 경로와 최신 상태 경로는 그대로 유지한다.
