# 일별 집계 규칙

v0.8.13 상태: compact 원장 기반 시간 비례 자정 배분을 구현했다. 주차 SOC와 전체
SOC는 미확인이다. 측정 표본 기반 정밀 자정 배분·link 보정·당시 유가 비교는 후속
구현이다. 아래는 유지할 최종 계약이며 미구현 동작을 운영 보장으로 읽지 않는다.

## 시간·장기 보존

HA 시간대를 차량 최초 등록 시 고정해 기록한다. 하루 구간은 local midnight에서
다음 local midnight까지 [start,end)이며 UTC에서 계산한다. DST 날을 24시간으로
가정하지 않는다. 시간대 설정 변경은 새 관측부터 적용하며 기존 날짜는 자동으로
이동시키지 않는다. 전체 과거 시간대 재집계는 백업 후 별도 명시적 작업이다.
조회 기간은 한 시간대 기준이다. 시간대가 다른 parts를 그대로 합치지 않는다.

일별 요약, trip/charge/parking의 간결한 원장, day_parts, 수동 기록·사진·비용·
비교 기준은 자동 만료 없이 유지한다. raw state, 좌표 전체, 시간별 차트는 장기 저장하지
않는다. 장기 저장량·사진 bytes는 운영 상태에서 표시하고 사용자가 관리한다.

## 소비량과 측정 품질

거리 합계는 유효 trip 기록의 distance_km이다. 전비는 유효하고 같은 구간의
energy_distance_km 합계 / drive_energy_kwh 합계. 전체 거리로 나누거나 trip별
전비를 단순 평균하지 않는다. 유효 소비 에너지가 없거나 0이면 전비는 null이다.
커버리지는 energy_distance_km/전체 주행거리로 표시한다. manual/estimated 포함
여부를 별도 반환해 '측정 전비'와 추정 전비를 섞지 않는다.

주행 SOC는 검증된 주행 구간의 순소비(%p); parking 소비는 offroad·비충전·
연속 관측 구간의 순소비다. 회생 증가분을 각각 소비로 세지 않고 구간 순변화를 쓴다.
SOC 경계만 있으면 경계 차이를 추정으로 표시한다. 기존 energy/derivation의
품질 판정을 재사용하고 CAN 초기값·stale 측정은 제외한다.

주차 state 연속성은 두 관측 모두 parked/noncharging이고 측정 시각 차이가 90초
이하인 경우만 기본 인정한다. 단순 cloud 확인 시각은 측정 시각이 아니다. 공백·상태
전환을 넘겨 보간하지 않는다. valid seconds를 구간 union으로 계산한다. 하루 전체
관측 seconds가 실제 하루 길이를 덮고 진행 중/미분류 구간이 없을 때만 total SOC를
확정한다. 그 외 주행·주차 부분값은 보여 주되 전체값은 null과 부분 관측이다.
용량×SOC로 누락 kWh를 발명하지 않는다. 향후 실측으로 기준을 바꿀 때 버전을 올린다.

## 자정·횟수·비용

자정 경계에 표본이 있으면 실제 구간 변화로 배분한다. 표본이 없으면 동일 원장의
거리·에너지·SOC를 날짜별 elapsed UTC seconds에 비례해 나누고 time_prorated로
표시한다. 시작=종료인 합성/legacy 기록은 시작일에 배분한다. 모든 parts 합계는
원장 합계와 일치해야 한다. charging count는 started_at의 날짜에만 1을 둔다.

기존 CAN mode 4는 slow, 6은 fast다. 그 외 기존 평균전력 fallback 판정을
재사용할 경우 estimated로 표시한다. fallback 근거가 없으면 unknown이고 slow로
강제하지 않는다. 분류 원천·버전을 남긴다.

자동 충전 비용은 기존 결제 그룹의 시작일, 수동 비용은 입력한 지출일에 귀속한다.
paid_date는 별도다. 에너지를 날짜별로 나누더라도 비용을 중복 배분하지 않는다.
실제·추정 모두 저장하되 effective는 actual 우선, actual null일 때 estimated다.
카테고리 총지출은 effective 합계이고 actual-only 합계를 따로 제공한다.
모든 조회는 active만 집계하고 excluded/deleted/superseded는 제외한다.

## 늦은 기록·수동 보완·재계산

당일 또는 진행 중 원장은 provisional이다. 일 마감 후에도 지연 수신·수정으로
재계산될 수 있으므로 '확정'은 영구 불변이라는 의미가 아니다.
자동 누락 보완 manual은 독립 보존하되 자동 재도착 후보는 시간·차량·종류로 표시한다.
유사하다는 이유로 자동 삭제/병합하지 않는다. 사용자가 link를 결정하기 전 해당
날짜는 중복 후보 품질을 표시한다. replaces이면 manual 대체값만, supplements이면
지정 필드만 보완하고 거리·에너지를 두 번 더하지 않는다.

원장·보정·결제·제외 변경은 dirty generation을 증가시킨다. 집계 transaction은 읽은
동일 generation일 때만 dirty를 지운다. aggregate 실패 시 기존 summary에 stale 상태를
표시하고 재시도한다. 원본 parts와 summary 교체는 원자적으로 수행한다.

## 유류비 비교

current_basis는 선택 기간 거리 / 현재 비교 연비 × 현재 HA 센서 가격이다.
historical_basis는 각 날짜 거리 / 선택 비교 연비 × 그 날짜의 관측 가격 평균이다.
평균은 날짜 안에서 실제 관측된 유효 가격의 산술평균으로, 시각·표본수도 반환한다.
관측 없는 날짜는 직전/현재 가격으로 채우지 않으며 해당 날짜와 비용은 null이다.
부분 비교는 같은 날짜 범위의 충전비만 차감하고 비교 커버리지를 표시한다.
절감액은 음수도 허용하며 충전비와 예상 유류비만 비교한다. 총 보유비 절감으로
표현하지 않는다. 최신 기준 재비교와 당시 기준 비교를 구분해 선택 설정을 반환한다.
