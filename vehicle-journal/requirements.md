# 확정 요구사항

## 목적과 경계

일·주·월·연도별 차량 생활 기록을 HA 내부에서 조회·비교할 수 있는 기반을 준비한다.
장기 최소 단위는 하루다. 자동 기록 외에 사용자 수동 기록을 일급 데이터로 보존한다.
디자인 선택·후보 재제작·이관·실행 연결은 이번 범위에서 제외한다.
사용자 추가 요청으로 빈 운영 HA DB 생성까지 포함했다.

현재 차량 수집은 기존 cloud 경로를 그대로 쓴다. 'HA 전용'은 차계부 장기 저장,
집계, 조회, 수동 쓰기를 의미하며 기존 cloud 데이터 제거나 cloud 없는 수집 전환은 아니다.

## 데이터 요구

- 주행: 거리, 동일 구간 소비 에너지·전비, 주행 소비 SOC(%p), 계기판 거리.
- 주차: 관측된 주차 SOC 소비와 관측 시간·공백. 미관측 소비를 만들어내지 않는다.
- 충전: 배터리 유입 kWh, 별도 청구 kWh, SOC 증가, 완속/급속/미확인 횟수,
  실제·추정 충전금액, 기본 귀속일과 별도 결제일, 장소·메모.
- 수동 관리: 타이어·와이퍼·워셔액·소모품 교체·일반 정비·튜닝·세차·기타,
  작업 날짜, 원 단위 금액, 메모, 사진. 보험·세금·주차·통행료도 별도 비용 분류.
- 누락 보완: 수동 주행·충전과 자동 기록 보정. 자동 기록 재도착 시 중복 방지.
- 품질: measured/estimated/manual/missing/partial, 근거 출처, 수집 공백,
  거리·SOC 관측 범위, 집계 버전, 잠정 여부. 사실과 계산 결과를 구분한다.

## 향후 화면과 데이터 연결

| 화면 | 로컬 데이터 |
| --- | --- |
| 월간 요약·도넛 | 비용 원장, 실제·추정 금액, 대분류별 합계 |
| 주행·충전 통계·복합 차트 | 일별 거리·소비·충전·비용·횟수, 가중 전비 |
| 유류비 비교 | 기간 거리·충전비, 유종·연비 설정, HA 유가 관측값 |
| 정비·소모품 | 수동 비용 원장·세부분류·메모·첨부파일 |
| 차량 상태 | 기존 실시간 HA cache/coordinator; journal 계산에 대기하지 않음 |

1일/1주일/1개월 선택은 일별 원장 기반 기간 조회다. 하루 안의 시간별 장기 차트는
지원 약속에 포함하지 않는다. 화면은 친근하고 정중한 `~해요` 어조를 사용한다.

도넛의 정비/소모품은 maintenance 세부분류를 합친다. 보험·세금·주차·통행료는 DB에서
분리하며 기존 5분류 화면에서는 '기타' 아래 묶을 수 있다. 원장을 버리지 않는다.

사진 기본: JPG/PNG/WEBP, 파일당 2MiB, 활성 사진 최대 5장/기록.
초기 쓰기·사진 조회는 HA 관리자, 일반 기록 조회는 해당 통합 접근이 허용된 로그인 사용자다.
